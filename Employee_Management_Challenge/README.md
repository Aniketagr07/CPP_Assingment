Employee Management System — C++

A C++ program demonstrating constructor overloading, function overloading, and copy constructors through a dynamic employee management system.

The program supports multiple ways of creating employee records, flexible salary calculations including bonuses, overtime, and tax deductions, and selective profile updates for department and salary. The main() function demonstrates all overloaded constructors and methods.

Concepts Used:
Classes & Objects • Constructor Overloading • Copy Constructor • Function Overloading • Encapsulation • Dynamic Pay Calculation
